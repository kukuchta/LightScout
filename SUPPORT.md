# Support

LightScout is a hobby project made and maintained by one person in their spare time.

## What to expect

- Help is **best effort**. There is no guaranteed response time and no guarantee that a problem will be fixed.
- **No medical advice and no emergency help.** For anything about treatment, ask your diabetes team. In an
  emergency, call your local emergency number.
- Questions are answered in English or Polish.

## Where to go

| You want to… | Go to |
|---|---|
| Ask a question, get help with setup, share an idea | [Discussions → Q&A / Ideas](https://github.com/kukuchta/LightScout/discussions) |
| Share a setup that works for you | [Discussions → Setups](https://github.com/kukuchta/LightScout/discussions) |
| Report a bug you can describe and repeat | [Issues → Bug report](https://github.com/kukuchta/LightScout/issues/new/choose) |
| Report a security problem | Privately, see [SECURITY.md](SECURITY.md). Never in a public issue. |
| Follow important news (for example a problem with alarms after an Android update) | [Discussions → Announcements](https://github.com/kukuchta/LightScout/discussions) |

If you are not sure whether it is a bug, start in Discussions; it can be turned into an issue later.

## Before you report

- Read the [FAQ](docs/faq.md) and the [known limitations](docs/limitations.md).
- Note the LightScout version (Settings → About), your phone model and Android version, your Nightscout version
  and your uploader.
- **Never post your Nightscout address, access token, `API_SECRET` or screenshots with real readings** in a public
  issue or discussion. Hide them first.
