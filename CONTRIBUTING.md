# Contributing

Thank you for wanting to help. LightScout is a one-person hobby project, so please keep contributions small and
talk first about anything larger.

- **Bugs:** open an [issue](https://github.com/kukuchta/LightScout/issues/new/choose) with the bug report form.
- **Ideas and questions:** use [Discussions](https://github.com/kukuchta/LightScout/discussions).
- **Code:** open an issue or discussion first, then a pull request. Read [docs/development.md](docs/development.md)
  for the environment and the rules, and run `./gradlew build` before you push.
- **Translations:** welcome; open a discussion first so the terms stay consistent.

By contributing you agree that your contribution is licensed under the GNU General Public License v3.0 or later,
like the rest of the project.

Never include real Nightscout addresses, tokens or health data in issues, pull requests, tests or screenshots.
